## 🎯 Project Overview

Ocean Sentinel is an innovative AI-powered platform that combines **NASA's cutting-edge satellite technology** with **autonomous cleanup systems** to tackle global ocean plastic pollution. By leveraging real-time NASA CYGNSS, MODIS, and Sentinel satellite data, our system identifies plastic hotspots and deploys AI-optimized cleanup missions.

### 🌍 Problem We're Solving
- **8 million tons** of plastic enter oceans annually
- **5 trillion pieces** of plastic currently pollute our oceans
- Traditional cleanup methods are **inefficient and costly**
- Lack of **real-time detection** and **coordinated response**

### 💡 Our Innovation
Ocean Sentinel is the **first system** to combine:
- 🛰️ **NASA Satellite AI** for real-time plastic detection
- 🤖 **Autonomous Route Optimization** using advanced algorithms
- 📊 **Predictive Analytics** for plastic accumulation patterns
- 🌊 **Digital Ocean Twin** for mission simulation

## 🚀 Technical Architecture

### 🧠 **AI/ML Pipeline**
```

Plastic Classification → Route Optimization → Mission Deployment
```

## 🎨 Getting Started

### 📋 Prerequisites
- Node.js 18+ 
- npm or yarn
- Modern web browser

### 🚀 Quick Start
```bash
# Clone the repository
git clone https://github.com/ashikulbarichy/ocean-sentinel.git

# Navigate to project directory
cd ocean-sentinel

# Install dependencies
npm install

# Start development server
npm run dev

# Open browser to http://localhost:5173
```

### 🔧 Build for Production
```bash
# Build optimized version
npm run build

# Preview production build
npm run preview
```
